# Plugins-Visitas-WP

Plugin **WP Métricas** para WordPress.

## Instalación manual

Copia `wp-metricas/` a `wp-content/plugins/` y actívalo.

## Versión actual

**1.1.0** — preparada para envío a WordPress.org

## Enviar a WordPress.org

1. Crea cuenta en https://wordpress.org/support/register.php
2. Envía el plugin en https://wordpress.org/plugins/developers/add/
3. Sube un ZIP con la carpeta `wp-metricas/` (genera con `zip -r wp-metricas.zip wp-metricas/`)
4. Usa el usuario de WordPress.org como `Contributors` en `readme.txt`
5. Tras la aprobación, sube el código al repositorio SVN que te asignen
