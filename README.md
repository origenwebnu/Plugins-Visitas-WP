# Plugins-Visitas-WP

Plugin **Origen Web Analytics** para WordPress.

## Instalación manual

Copia `origen-web-analytics/` a `wp-content/plugins/` y actívalo.

## Versión actual

**2.0.0** — preparada para WordPress.org

## Enviar a WordPress.org

1. Crea cuenta en https://wordpress.org/support/register.php
2. Envía el plugin en https://wordpress.org/plugins/developers/add/
3. Sube un ZIP con la carpeta `origen-web-analytics/`
4. Usuario de WordPress.org: **origenweb**
5. Ejecuta Plugin Check antes de enviar
