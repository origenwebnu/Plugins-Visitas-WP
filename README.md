# Plugins-Visitas-WP

Plugin **Métricas y Análisis OW** para WordPress.

## Instalación manual

Copia `metricas-analisis-ow/` a `wp-content/plugins/` y actívalo.

## Versión actual

**1.1.2** — preparada para WordPress.org

## Enviar a WordPress.org

1. Crea cuenta en https://wordpress.org/support/register.php
2. Envía el plugin en https://wordpress.org/plugins/developers/add/
3. Sube un ZIP con la carpeta `metricas-analisis-ow/`
4. Usuario de WordPress.org: **origenweb**
5. Ejecuta Plugin Check antes de enviar
